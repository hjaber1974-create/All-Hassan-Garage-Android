# Hassan Garage Android

Android app for Hassan Garage in Gambia.

Current first version includes:
- Quick sales entry with a visible confirmation after sale
- Vehicle intake
- Default D 100 parking/entry fee
- Repair notes
- Search screen
- Inventory placeholder
- GitHub Actions APK build

Planned next:
- Persistent local database
- Inventory quantities and stock deduction after sale
- Invoices and printing/PDF
- Arabic + English language switch
- WhatsApp customer notifications
- Reports and profit tracking
